FamiStudio Extended R13 — Development preview / 开发预览版
Based on FamiStudio 4.5.3 / 基于 FamiStudio 4.5.3
Project format / 工程格式：1011

中文

• 工程属性 → 信息新增“PCM 采样率”，可选择约 4、8、16、32 kHz。
  适用于 2A03、MMC5 和 VRC6 的 PCM 编辑、试听及音频导出。
• 切换采样率会从保留的源数据重新采样，保持音高和时长；不改变音乐更新率、
  钢琴窗网格或 DPCM 采样设置。支持保存、撤销、重做和文本导入导出。
• 高采样率保留更多高频细节，同时增加 CPU、内存和采样数据量。
  工程属性会显示当前制式的实际采样率和性能提示。
• NSF、NSFe、NES 和声音引擎仅提供约 4 kHz 的兼容 PCM 导出。
  高采样率工程须明确选择兼容重采样，导出副本保留音高和时长，原工程不变。
  当前通用 6502 驱动无法保证更高采样率的中断时限，因此不提供相应导出档位。
• 修正 PCM 声音引擎导出的制式选择。既有芯片、并发声部和 CPU 预算限制继续适用。
• 新控件和提示适配全部七种语言。工程格式升级至 1011，旧工程仍可打开；
  新保存的工程需要 R13 或更新版本。

English

• Add PCM sample rate to Project Properties → Information, with approximately
  4, 8, 16 and 32 kHz options for 2A03, MMC5 and VRC6 editing, audition and audio export.
• Resample retained source data when changing rates while preserving pitch and
  duration. Music updates, piano-roll resolution and DPCM settings remain independent.
  Project saves, undo/redo and text interchange retain the selected rate.
• Higher rates preserve more high-frequency detail and increase CPU work, memory
  and PCM data size. The dialog shows the actual regional clock and performance notes.
• NSF, NSFe, NES and sound-engine export offer only the approximately 4 kHz compatible
  PCM clock. Higher-rate projects require an explicit compatible resampling choice.
  The exported copy retains pitch and duration; the original project is unchanged.
  Higher hardware-export rates are unavailable because the current general-purpose
  6502 driver cannot meet their per-sample interrupt deadlines reliably.
• Correct region selection for PCM sound-engine export. Existing chip, concurrency
  and CPU-budget restrictions still apply.
• Localize all new controls and messages in all seven supported languages.
  Project format is now 1011. Existing projects load normally; new saves require R13
  or newer.

FamiStudio Extended R12 — Development preview / 开发预览版
Based on FamiStudio 4.5.3 / 基于 FamiStudio 4.5.3
Project format / 工程格式：1010

中文

新增与改进

• DPCM 与 PCM 使用独立采样库，分别管理源文件、加工参数、文件夹和排序。
  两库可使用相同名称，修改或删除其中一份不会改变另一份。
• 2A03 乐器共用一个键位映射界面，每个键可选择 DPCM 或 PCM。
  PCM 通过原生 7 位 DAC 播放，与 DPCM 轮流占用同一个硬件声部。
• MMC5 乐器支持 PCM 键位映射，仅接受 PCM 采样。独立 8 位 PCM 通道
  可与原生五声部及 MMC5 两个方波同时编曲。
  普通 2A03 乐器的 PCM 键位也可直接在 MMC5 PCM 通道使用。
• VRC6 乐器增加采样映射。两个方波通道分别支持 4 位 PCM，播放期间
  占用对应方波，普通未映射音符可恢复方波演奏；锯齿波保持原有功能。
• PCM 支持移调、循环、音量、实时声像、波形编辑、试听及音频导出。
• 声音引擎和 NSF2 导出支持上述输出目标，包含 PCM 与普通音色的切换。
  NES 播放器按输出芯片选择专用模板。
• 保存、文本导入导出、复制粘贴、撤销、清理及工程合并均识别两套采样库。
  R11 工程打开时自动拆分旧共享采样，保留 DPCM 原始数据和 PCM 声音。
• 新界面与提示适配现有七种语言。
• 工程的 1×/2×/4× 更新率同步转换编辑网格，保留既有音乐速度和包络时长。
  4× 网格可在 NTSC 240 Hz / PAL 200 Hz 的时间精度上放置音符。
  无法精确表示的转换会说明原因并保留原工程。
• “另存为”使用独立的工具栏图标，保留快捷键与各语言提示。
• 修正相同 BPM 的不同节奏排列选择，以及起始填充节奏在 NSF 导出中的首帧偏移。

兼容性

• PCM 需要 CPU 持续供样。编辑器与 NSF2 使用约 4 kHz 的采样时钟，
  与音乐的 1×/2×/4× 更新率独立。这是当前驱动的实现选择，并非硬件采样率上限。
  硬件有效精度取决于所选输出芯片。
• 含 PCM 的 NSF/NSFe 导出需要支持 NSF2 IRQ 的播放器，并选择与工程相同的
  PAL/NTSC 制式。
  多路 PCM 与音乐更新共享 CPU 预算；超载组合会拒绝导出。
• 含 PCM 的 NES 为 1× 静态音乐播放器。含 MMC5 的工程使用 mapper 5，仅原生 APU
  或使用 VRC6 的工程使用 mapper 24；2A03 PCM 的 NES 文件不是 NROM。NES 采样时钟与
  NSF2 不同，导出时重新采样以保持音高与时长。
  当前 NES 模板同时只支持一路 PCM，不同 DAC 可交替，重叠会拒绝导出。
  PCM NES 仅支持原生 APU、单 MMC5 或单 VRC6 布局，不支持任意多扩展组合。
• 集成到 FC 游戏需要协调采样中断、换页、音乐更新和画面工作。
  2A03 DAC 还会通过原生非线性混音影响三角波和噪波的实际响度。
• NSF2 PCM 暂不与 EPSM 同时导出。不支持 PCM 的格式会明确拒绝导出。
  NSF 导入尚不支持将软件 PCM 重建为可编辑采样轨道。
• 新工程格式为 1010，旧版本不能打开新保存的文件。Windows 原生库
  随本版更新；其他平台也必须重建原生库，不能只替换托管程序集。

既有功能

歌曲和样式的独立调音、工程级芯片调律曲线、多子曲 NSF 导入、实时声像、
可重复扩展芯片、保留既有速度的更新时钟、硬件演奏参数及“另存为”继续
保留。Gimmick! 示范曲扩充至四首，利用扩展功能再现游戏中的演奏效果，
并保留原工程名称与作者信息。

English

Added and improved

• Independent DPCM and PCM libraries, with separate source data, processing,
  folders and ordering. Matching names across libraries remain distinct assets.
• One keyboard map for 2A03 instruments, with either DPCM or PCM assigned to
  each key. PCM uses the native 7-bit DAC and shares its physical voice with DPCM.
• PCM-only keyboard mappings for MMC5 instruments. The independent 8-bit PCM
  voice complements the five APU voices and the two MMC5 pulse voices.
  Regular 2A03 instruments' PCM keys can also be used directly on MMC5 PCM.
• Sample mappings for VRC6 instruments. Each pulse can play 4-bit PCM while
  occupying that pulse. Unmapped notes resume ordinary pulse playback.
  The sawtooth channel retains its existing behavior.
• PCM transpose, looping, volume, live pan, waveform editing, audition and
  audio export.
• Matching sound-engine and NSF2 outputs, including PCM/ordinary-voice handoff.
  NES music-player export selects a dedicated template for its output chip.
• Separate libraries throughout saving, text interchange, clipboard, undo,
  cleanup and project merging. R11 shared samples migrate automatically,
  preserving the original DPCM data and PCM sound.
• Controls and messages in all seven existing languages.
• Project 1×/2×/4× changes convert the editing grid while retaining musical
  speed and envelope duration. The 4× grid supports note placement at NTSC
  240 Hz / PAL 200 Hz resolution. Inexact conversions leave the project intact.
• A dedicated Save As toolbar icon, with localized help and the existing shortcut.
• Correct selection of different grooves with the same BPM and first-frame timing
  for beginning-padded grooves in NSF exports.

Compatibility

• Software PCM requires continuous CPU service. Editor and NSF2 sample clocks
  are approximately 4 kHz, independent of 1×/2×/4× music updates. Hardware
  output precision depends on the selected destination. This rate is an
  implementation choice, not a fixed hardware sample-rate ceiling.
• PCM NSF/NSFe exports require an NSF2 IRQ-capable player and the project's
  explicit region.
  Concurrent PCM and music updates share a CPU budget. Overload is rejected.
• PCM NES export is a static music player with 1× music updates. MMC5 projects use
  mapper 5; APU-only and VRC6 projects use mapper 24. The APU PCM NES player is not NROM.
  Samples are resampled for the NES clock to preserve pitch and duration.
  Current NES templates allow one active PCM voice, with alternating DACs.
  Overlapping PCM is rejected.
  PCM NES supports base APU, one MMC5 or one VRC6, not arbitrary multi-expansion
  layouts.
• Game integration must coordinate interrupts, banking, music and graphics.
  Native 2A03 nonlinear mixing also lets DAC output affect triangle/noise gain.
• NSF2 PCM currently cannot coexist with EPSM. Unsupported formats reject PCM.
  NSF import does not reconstruct editable software-PCM sample tracks.
• New saves use format 1010 and require this revision or newer. Windows native
  libraries are included. Other platforms also need rebuilt native libraries.

Existing features

Song/pattern tuning, project-wide chip curves, multi-subsong NSF import, live
pan, optional chip copies, speed-preserving update clocks, hardware articulation
and Save As remain available. The Gimmick! demonstration contains four songs,
using the extended features to reproduce the game's musical effects while
retaining the original project title and author credits.
